## 🚀 AFC-7 智能飞控板 - 底层环境一键安装与验证指南

**平台架构**：AFC-7 新一代智能飞控（双核异构平台）
**文档版本**：V1.1.260530 
**开源平台**：[zqhkd/AFC-7Published: AFC-7 智能飞控软件开发平台](https://github.com/zqhkd/AFC-7Published)

**作   者**: 曾庆华
**发行单位**: 卓飞智控技术有限公司 (Zhuofei Zhikong Technology Co., Ltd.)

欢迎使用 AFC-7 (Intelligent Flight Controller) 专属的 Linux 板级支持包 (BSP) 一键部署工具。本指南将协助您在 1 分钟内全自动完成**底层 RIF（资源隔离框架）权限刷新**与**系统冗余服务净化**，彻底打通 M33 飞控核心对 HPDMA1/3 的合法越界访问权限，为强实时飞控算法打造纯净的硬实时运行环境。

---

### 📁 目录文件清单
在执行安装前，请确保您的上位机 WSL2/Linux 部署目录下包含以下完整文件清单（缺一不可）：

* **`AFC7LinuxBSPSetUp.sh`**：一键自动化部署主脚本（负责调度、安全推送与闭环逻辑校验）。
* **`myb-afc7-2GB.dtb`**：AFC-7 专属编译的底层设备树固件。
* **`myb-stm32mp257x-2GB_extlinux.conf`**：双启动引导配置文件（确立 A/B 分区防变砖安全网）。
* **`fip-myb-stm32mp257x-2GB-optee-emmc.bin`**：底层 RIF 核心权限固件映像（用于重构 A35 与 M33 的总线权属）。
* **`ttt-ip-init-systemd.sh`**：TSN（时间敏感网络）网络核心加载与功能裁剪脚本。
* **`issue`**：AFC-7 专属的串口终端 ASCII 欢迎界面配置文件。
* **`check_afc7_hw.sh`**：硬件资源全景巡检与权属确认脚本。

---

### ⚠️ 运行前核验与避坑指南（重要）
为了确保一键安装流畅通过，请在执行脚本前花 10 秒钟确认以下两点：
1.  **首次连接握手阻塞**：如果您的 WSL2 终端是第一次连接这块飞控板，请先在终端手动运行一次 `ssh root@192.168.0.10`，并在弹出的提示中输入 `yes` 接受密钥指纹。否则脚本在后台执行 scp 时会被 SSH 安全提示卡死。
2.  **多网卡路由冲突**：请确保上位机电脑当前没有挂载冲突的虚拟网卡，可以在 WSL2 中优先 `ping 192.168.0.10`，确保网络通路绝对畅通。

---

### 🛠️ 第一步：一键极简安装 (在电脑 WSL2 / Linux 端执行)
请在您的电脑 WSL2 终端中，**进入本脚本所在目录**（严禁在外部跨路径调用）。

> 💡 *提示：如开发板 IP 有变动，请先用文本编辑器打开 `AFC7LinuxBSPSetUp.sh`，修改开头对应的 `TARGET_IP` 变量（默认已固化为 `192.168.0.10`）。*

无需更改任何文件权限，直接执行以下命令：

```bash
bash AFC7LinuxBSPSetUp.sh
```

🛡️ 自动化脚本执行核心逻辑：
静态资源推送：自动同步外设设备树、双启动 extlinux 配置、专属 issue 欢迎页。

系统净化裁剪：自动下发远程指令，永久关闭并屏蔽（Mask）掉已丢弃的旧 eeprom 序列号服务（eeprom-pnsn.service）及连带的温控冗余服务（st-thermal.service）。

FIP 固件安全闪刷：脚本自动将 FIP 映像推送到板载暂存区，利用底层的 dd 指令对 eMMC 的安全启动分区（mmcblk1p3/p4）进行强刷，并在写入后立刻强制进行硬件层 sync 总线同步。

安全拦截机制：脚本具备严格的原子级闭环保护。若网络中途断开或 eMMC 块设备触发写保护导致强刷失败，脚本会自动拦截后续的 reboot 指令并红字高亮报警，从根源上杜绝飞控板因固件残缺而变砖。

当终端提示 “AFC-7 系统一键部署完毕！开发板正在进行热重启...” 时，您即可将目光转向开发板的串口终端屏幕。

✅ 第二步：系统核验与深度验证 (在开发板串口终端执行)
开发板热重启过程中，请通过串口工具（如 MobaXterm）全程监测系统跑码流。🟢 正常情况下，整个启动日志中<font color="red">**不应出现任何红色的错误报警信息**</font>。启动完成并成功登录飞控板终端后，请进行以下两项核心指标的验收：

(1) 检查 AFC-7 专属品牌欢迎页
在系统内核跑码结束后，弹出 login: 登录提示符之前，检查屏幕是否成功输出了如下带有卓飞智控技术特征的专属 ASCII 欢迎界面：

Plaintext

验收标准：成功看到此界面，说明基础引导配置已完美接管系统。请输入用户名 root 登录。

(2) 运行硬件全景巡检与服务净化核验
登录系统后，我们需要确认两点：一是冗余服务是否确实被纯净化裁剪；二是 A35 内核是否已彻底释放硬件外设控制权，打通 M33 侧的专属总线边界。

请在板载终端依次执行以下核验指令：

```Bash
# 1. 核验机器型号与硬件平台
dmesg | head -n 5
# 验收标准：输出的第 4 行必须精准显示：Machine model: AFC-7 Flight Controller based on MYiR STM32MP257x

# 2. 运行一键全景巡检工具
./check_afc7_hw.sh
```

验收标准：仔细核对巡检脚本打印的绿色资源归属清单：

[串口资源]：Linux 侧仅保留调试串口 ttySTM0，禁止出现飞控专用的 ttySTM1/3/4/6/8/9。

[硬实时总线]：Linux 侧的 SPI 主机目录应为空；PWM 目录应为空；I2C 资源中彻底消失 1 和 3（已完全让渡给 M33 核心驱动）；无飞控专属 ADC 节点。

[A35 机载生态]：USB Root Hub、机载高速摄像头与硬件编解码节点（video0 ~ video6）保持正常挂载，供上层航电与视觉算法调度。

🎉 恭喜！ 如果以上核验项目全部绿灯通过，标志着 AFC-7 异构双核系统的总线控制权边界已正式确立，底层 RIF 防火墙隔离全面生效，您可以放心交付团队进行上层飞控软件开发！
